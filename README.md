# The Hostess

Restaurant ordering and table reservation system.

## Live demo

Visit [The Hostess](https://the-hostess.vercel.app), or scan this QR code:

![QR code to open The Hostess](./hostess-qr.png)

## Project description

Restaurants lose time and money taking orders and reservations manually. The Hostess lets customers browse a digital menu, place orders, and reserve tables online. The kitchen receives orders in real time, while the owner can manage the restaurant and view sales reports.

## Key features

- Digital menu with categories, images, and customizable options
- Cart, order placement, and live order status
- Table reservations with time-slot availability
- Real-time kitchen order display
- Owner dashboard with daily sales reports and restaurant management

## Technology

- **Client:** React, Vite, React Router, Tailwind CSS, Zustand, Recharts, Socket.IO Client
- **Server:** Node.js, Express, MongoDB Atlas, Mongoose, Zod, Socket.IO
- **Image storage:** Cloudinary
- **Hosting:** Vercel (client), Railway (server)
